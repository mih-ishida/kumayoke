# Mile2 Repository Usage

Mile2は、美笛キャンプ場向けの「施設別クマ出没マップ」試作を進めるための作業領域である。

## 基本ルール

- `_requirements/` は固定文書専用とし、作業メモを混ぜない。
- ひぐまっぷは、自治体が住民向けに公開した情報を探す補助として扱い、ログイン後データ・非公開API・画面表示データを直接利用しない。
- `phase2_source_research/` は生の調査メモと出典確認メモを置く。
- `phase3_internal_table/` は公開判断済みの内部正本を置く。
- `phase4_map/` は地図仕様メモと作業用素材を置く。
- `phase5_web_email/` はWeb掲載文とメール差し込み文の確定版を置く。
- `phase6_publish_check/` は公開前チェックメモを置く。
- `web/` は公開用ファイル専用とし、内部メモを置かない。

## 公開用の置き場

- 公開HTML更新先: `web/f/bifue-camp.html`
- 公開地図画像: `web/assets/bifue-camp-bear-map.png`

## コミットしないもの

- 非公開・会員向けサービスから直接写したデータ
- 私的サービスの転載物やスクリーンショット
- 一時ダウンロードやローカルキャッシュ
- 公開に不要な重い途中書き出し物
- 個人情報や送信履歴を含む運用メモ
