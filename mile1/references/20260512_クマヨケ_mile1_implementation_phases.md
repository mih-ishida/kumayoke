# クマヨケ 第一マイルストーン実行Phase

## 位置づけ

このPhase表は、第一マイルストーン要件固定版を実行するための進行管理メモである。

詳細な要件・方針・文面・FAQ・完了条件は、原則として「クマヨケ 第一マイルストーン 要件固定版」を正とする。
この文書では、要件本文を重複して管理しない。

# 運用ルール

## 1. 要件の詳細はここに書かない
詳細な方針、表現、対象、FAQ、メール文面は要件固定版を参照する。

## 2. Phase表は作業順だけを管理する
この文書では、何をどの順番で作るかだけを管理する。

## 3. 要件変更が出たら要件固定版を更新する
Phase表は原則として更新しない。
更新する場合は、作業順や成果物に影響があるときだけにする。

## 4. 成果物名は要件固定版と合わせる
成果物の呼び方がズレると保守が大変になるため、要件固定版の名称に合わせる。

## 5. 完了判定は要件固定版で行う
このPhase表の完了条件は進行確認用。
最終的な完了判定は、要件固定版の完了条件で行う。
