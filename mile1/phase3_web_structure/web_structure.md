# Phase3 Webページ構成案 v2（mile1）

## ページタイトル
宿泊者向け クマ撃退スプレー貸出運用の導入相談 | クマヨケ

## セクション順と各セクションの目的

| # | セクション名 | 答える不安・問い |
|---|---|---|
| 1 | ファーストビュー（H1・リード） | 「これは何の話か」をスクロールせずに判断できる |
| 2 | 30秒でわかるクマヨケ | 「どんな内容か」の骨格を素早く把握できる |
| 3 | 対象施設 | 「うちに関係があるか」をセルフチェックできる |
| 4 | 役割分担のイメージ | 「フロントに何をさせるのか」「何が用意されるのか」が分かる |
| 5 | 運用前提と責任分担の考え方 | 「事故やトラブルのとき誰が責任を負うのか」への基本方針が分かる |
| 6 | 返信しても導入確約にはなりません | 「返信したらしつこい営業になるか」への答えが分かる |
| 7 | よくあるご質問（4〜5問） | 残る具体的な疑問を短く解消できる |
| 8 | 事業者情報 | 「誰が運営しているのか」「怪しくないか」を確認できる |
| 9 | 小さな注記 | 申込・決済・個人情報取扱の方針を短く確認できる |
| 10 | 15分ヒアリングのご案内（CTA） | 「どう返信すればいいか」「次のステップが何か」が分かる |

## 各セクションの要点

### [1] ファーストビュー
- H1「宿泊者向け クマ撃退スプレー貸出運用の導入相談」でスクロール前に話題が分かる
- eyebrow「初回ご連絡メールの補足ページ」で文脈を提示（「営業メール」という語は使わない）
- リードで「信用確認ページ」「契約・販売なし」「15分ヒアリング or 返信につなげる」を明示

### [2] 30秒でわかるクマヨケ
- 遭遇回避を前提とした安全補助オペレーション導入支援（スプレー販売でも登山ガイドでもない）
- 3要素を一式で用意する内容であることを明示
- 3カラムカード：備品／書類／運用設計（「運用」ではなく「運用設計」で統一）

### [3] 対象施設
- 支笏湖・定山渓・千歳周辺など具体エリア名を提示
- 温泉旅館、ホテル、ゲストハウス、ロッジ、自然体験近接型の小規模施設まで、規模・形態は問わない旨を明記
- 「一律提案ではない」「相性を確認する段階」を明記

### [4] 役割分担のイメージ
- 2カラム：「施設様にお願いする作業」と「クマヨケ側で用意するもの」を並列表示
- 施設側の所要時間目安（1組あたり5〜10分）を明記
- 専門的な使用説明はスタッフ不要（説明資料側で標準化）を明記
- クマヨケ側の備品リストは備品／書類／運用設計の3グループで整理
- レンタル料収益は施設側計上の前提を明記

### [5] 運用前提と責任分担の考え方
- 安全保証表現は使わない
- 貸出対象の条件をリスト形式で明示（宿泊者限定・18歳以上・自然活動目的など）
- 責任分担の方向性を示す（クマヨケ側が一次窓口対応する想定）
- 「責任分担の前提を曖昧にしたままお話を進めることはありません」を末尾に追加
- 「個別にご相談」使用：1回目

### [6] 返信しても導入確約にはなりません
- 返信≠導入決定 を明示
- 関心が薄い場合は一文返信だけでよいと案内
- 繰り返し営業をしない前提を明記

### [7] よくあるご質問
**FAQ件数：5問**（4〜5問方針）

1. このページですぐに詳細条件を案内していないのはなぜですか
2. フロントの作業はどの程度ですか
3. ホテルがすべての責任を負う形になりますか
4. 宿泊者から受け取るレンタル料金はどちらの売上になりますか
5. 返信したら導入前提で話が進みますか

**削除・統合した項目：**
- 「うちの施設にも関係がありますか」→ [3]対象施設に統合
- 「飛行機への持込・預け入れはできますか」→ [5]運用前提に統合

### [8] 事業者情報
- 事業名：クマヨケ
- 代表：石田 通隆
- 事業形態：個人事業
- 所在地：北海道札幌市
- 事業概要：北海道内の宿泊施設向け 安全補助オペレーション導入支援
- 連絡先：kumayoke_info@classwolf.com

### [9] ミニ注記（事業者情報の下に配置）
- H2の独立セクションとしては設けず、事業者情報セクション内の小さなブロックとして配置
- 申込・決済・契約手続きなし
- 費用は運用条件確認後に個別相談（「個別にご相談」2回目）
- 情報の利用目的

### [10] CTA：15分ヒアリング
- 15分オンライン相談 or メール相談を受け付ける
- CTA内に「ご返信は短い内容で構いません」の返信例ブロックを配置する
- 返信例では、短文返信・確認だけの返信・断り返信も許容することを明示する
- メール記載項目案（施設名・担当者名・日程候補2〜3・気になる点）
- 件名例の提示（クマヨケについて（◯◯ホテル／◯◯旅館））
- ボタン文言：「メールでご連絡する」
- mailtoリンクに件名・本文テンプレートを付与（`?subject=クマヨケについて&body=...`）
- ボタン下に送信先アドレスを表示

## 構成上の制約と運用ルール

- 「個別にご相談」はページ内2回まで（[5]と[9]で使用）
- 「安全を保証」「完全なクマ対策」「事故ゼロ」「必ず防げる」等の表現は禁止
- 価格・金額・円表示は含めない
- FAQは4〜5問に厳守
- 独立した特商法・プライバシーポリシーページは作成しない（ページ内の注記にとどめる）
- 事業者情報のプレースホルダー（石田○○・北海道○○市等）は使用しない
