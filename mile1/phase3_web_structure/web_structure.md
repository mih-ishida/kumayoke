# Phase3 Webページ構成案 v3（mile1）

## ページタイトル
宿泊者向け クマ撃退スプレー貸出運用の導入相談 | クマヨケ

## ストーリー方針

「困りごと → 解決案 → 相談導線」の5段ストーリーで組み立てる。
サービス説明から入らず、宿泊施設側の小さな困りごとへの問いかけから始める。

## 各セクションの要点

### [1] ファーストビュー
- H1「宿泊者向け クマ撃退スプレー貸出運用の導入相談」でスクロール前に話題が分かる
- eyebrow「初回ご連絡メールの補足ページ」で文脈を提示（「営業メール」という語は使わない）
- リードで「相手の業務シーン（クマ対策を聞かれた経験／フロントで貸し出せる形を整えたい経験）への軽い言及」と「契約・販売を扱わない／15分相談 or 短文返信が目的」を述べる
- リード冒頭は「このページは〜信用確認ページです」というメタ説明から始めない

### [2] こうした場面はありませんか（新設）
- 宿泊施設側の小さな困りごとへの問いかけ段落
- 採用する問いかけ：
  1. 宿泊者の方から、クマ対策について聞かれることはありませんか
  2. 飛行機でクマ撃退スプレーを持ち込めない旅行者の方に、現地でどう案内していらっしゃいますか
  3. フロントで貸し出せる形にしたいと考えても、保管・同意確認・返却・未返却時対応まで整えるのは、施設様だけだと負担が大きいのではないかと思います
- 「思い当たる場面がありましたら、続きをご覧ください」で[3]へ送る
- 断定・社会煽りは禁止。問いかけ・推量で止める

### [3] フロントで貸せる状態を一式で用意します
- [2]を受けて、「先ほどの運用整備を、クマヨケは備品・書類・対応フロー一式でご用意します」と接続
- 遭遇回避を前提とした安全補助オペレーション導入支援（スプレー販売でも登山ガイドでもない）
- 3カラムカード：備品／書類／運用設計（運用設計の本文に「保管・同意確認・返却・未返却対応」を含める）
- 「クマヨケは〜です」というサービス自己紹介から始めない

### [4] こうした施設に関係があります
- 支笏湖・定山渓・千歳周辺など具体エリア名を提示
- 各カードに、具体的な会話シーン（登山に向かう宿泊者から聞かれた／新千歳到着の旅行者から聞かれた等）を1〜2文添える
- 温泉旅館、ホテル、ゲストハウス、ロッジ、自然体験近接型の小規模施設まで、規模・形態は問わない旨を明記
- 「一律提案ではない」「相性を確認する段階」を明記

### [5] フロント作業とクマヨケ側の用意
- 見出しは「役割分担のイメージ」ではなく「フロント作業とクマヨケ側の用意」（読み手の関心軸に寄せる）
- 2カラム：「施設様にお願いする作業」と「クマヨケ側で用意するもの」を並列表示
- 施設側の所要時間目安（1組あたり5〜10分）を明記
- 専門的な使用説明はスタッフ不要（説明資料側で標準化）を明記
- 施設側作業欄では「会計運用は施設様の方針に合わせて確認」と表記する（「ホテル会計へのレンタル料計上」は使わない）
- クマヨケ側の備品リストは備品／書類／運用設計の3グループで整理
- 運用設計の項目順は「保管／同意／返却／未返却対応／使用期限・個体番号管理」とし、[2]の困りごとと一対一対応で見せる
- レンタル料金の扱いは、施設側収益を基本案としつつ会計運用は個別確認、と2段で記述

### [6] 運用前提と責任分担の考え方
- 安全保証表現は使わない
- 貸出対象の条件をリスト形式で明示（宿泊者限定・18歳以上・自然活動目的など）
- 3層構造で見せる：「クマヨケ側で必ず用意するもの」「施設様にお願いする範囲」「個別確認になる項目」
- 末尾に「責任分担の前提を曖昧にしたままお話を進めることはありません。詳細条件は、実際の運用状況を踏まえて個別にご相談します。」
- 「個別にご相談」使用：1回目

### [7] よくあるご質問
**FAQ件数：5問**

1. 未返却や使用後の対応はどちらが行いますか（**新設・差し替え**）
2. フロントの作業はどの程度ですか
3. ホテルがすべての責任を負う形になりますか
4. 宿泊者から受け取るレンタル料金はどちらの売上になりますか
5. 返信したら導入前提で話が進みますか

**差し替えた項目：**
- 旧1問目「このページですぐに詳細条件を案内していないのはなぜですか」（こちら都合の質問のため削除）

### [8] 事業者情報 + ミニ注記
- 事業名：クマヨケ
- 代表：石田 通隆
- 事業形態：個人事業
- 所在地：北海道札幌市
- 事業概要：北海道内の宿泊施設向け 安全補助オペレーション導入支援
- 連絡先：kumayoke_info@classwolf.com
- ミニ注記：申込・決済・契約手続きなし／費用は運用条件確認後に個別相談（「個別にご相談」2回目）／情報の利用目的

### [9] CTA：15分ヒアリング
- 15分オンライン相談 or メール相談を受け付ける
- CTA内に「ご返信は短い内容で構いません」ブロックを配置する
- ブロック内には旧[6]の返信ハードル下げメッセージ（返信≠導入確約／一文返信OK／繰り返し営業しない）と返信例4パターンを統合する
- メール記載項目案（施設名・担当者名・日程候補2〜3・気になる点）
- 件名例の提示（クマヨケについて（◯◯ホテル／◯◯旅館））
- ボタン文言：「メールでご連絡する」
- mailtoリンクに件名・本文テンプレートを付与
- ボタン下に送信先アドレスを表示
- 末尾に「社内共有用1枚メモPDFを見る」リンクを配置（Webから1枚メモPDFへの導線）

## 構成上の制約と運用ルール

- 「個別にご相談」はページ内2回まで（[6]末尾と[8]ミニ注記で使用）
- 「安全を保証」「完全なクマ対策」「事故ゼロ」「必ず防げる」等の表現は禁止
- 価格・金額・円表示は含めない
- FAQは5問
- 独立した特商法・プライバシーポリシーページは作成しない（ページ内の注記にとどめる）
- 事業者情報のプレースホルダー（石田○○・北海道○○市等）は使用しない
- 「ホテル会計へのレンタル料計上」のような言い切り表現は使わない
