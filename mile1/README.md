# mile1: 第一マイルストーン

## 目的

宿泊事業者に対して、クマヨケの小規模導入相談メールを送れる状態にする。

## ディレクトリ構成

| ディレクトリ | 用途 |
|---|---|
| `_requirements/` | 正本・参考資料（要件定義書・再設計版・参考資料）。成果物とは分けて置く。 |
| `phase1_inventory/` | Phase1：作業対象の棚卸し |
| `phase2_web_policy/` | Phase2：Webページ方針の確定 |
| `phase3_web_structure/` | Phase3：Webページ構成案の作成 |
| `phase4_web_content/` | Phase4：Webページ本文の作成 |
| `phase5_web_publish/` | Phase5：Webページ公開準備 |
| `phase6_one_pager/` | Phase6：1枚メモの作成 |
| `phase7_email_template/` | Phase7：初回メールテンプレート作成 |
| `phase8_customization/` | Phase8：施設別カスタマイズ部品の作成 |
| `phase9_target_list/` | Phase9：送付先リスト・返信管理シート作成 |
| `phase10_send_package/` | Phase10：送信前パッケージ化 |
| `working/` | 作業中メモ・下書き（レビュー・再構成案など） |

## 参照ルール

- 各Phaseの作業では、`_requirements/` 配下の正本を優先参照する
- 現行の正本は `20260520_クマヨケ_mile1再設計版.md`（公開ページ方針）と `20260520_クマヨケ_要件再設計版.md`（内部要件）
- 旧要件固定版（`20260512_クマヨケ_第一マイルストーン要件.md`）は参考にとどめ、正としない
- Phase成果物（`phase*/`）には正本・参考資料を置かない
