# mile1: 第一マイルストーン

## 目的

宿泊事業者に対して、クマヨケの小規模導入相談メールを送れる状態にする。

## Phase一覧

| Phase | フォルダ | 内容 |
|---|---|---|
| Phase1 | `phase1_inventory/` | 作業対象の棚卸し |
| Phase2 | `phase2_web_policy/` | Webページ方針の確定 |
| Phase3 | `phase3_web_structure/` | Webページ構成案の作成 |
| Phase4 | `phase4_web_content/` | Webページ本文の作成 |
| Phase5 | `phase5_web_publish/` | Webページ公開準備 |
| Phase6 | `phase6_one_pager/` | 1枚メモの作成 |
| Phase7 | `phase7_email_template/` | 初回メールテンプレート作成 |
| Phase8 | `phase8_customization/` | 施設別カスタマイズ部品の作成 |
| Phase9 | `phase9_target_list/` | 送付先リスト・返信管理シート作成 |
| Phase10 | `phase10_send_package/` | 送信前パッケージ化 |

## その他

- `references/` : 参考資料（手動コピー置き場）
- `working/`    : 作業中メモ・下書き
