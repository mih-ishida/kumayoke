## 1. 総評：現在ページで「実績がない印象」を出している表現

現状の共通ページ／施設別ページを読むと、信用確認ページとしては成立しているが、以下の表現が「まだ形になっていない／実績がない」印象を強めている。

| 箇所 | 現状表現 | 与える印象 |
|---|---|---|
| サブコピー（共通） | 「〜一緒に小さく試せないか検討しています」 | これから試す段階に見える |
| 補足文（共通・施設別） | 「契約や導入を前提としたものではなく、まずは可能性や不安点を伺うための説明ページ」 | 何も動いていない印象 |
| このページについて | 「〜取り組んでいる小規模事業です」「実際にニーズがあるか〜伺いたい」 | ニーズ調査の段階に見える |
| クマヨケとは | 「〜まとめて検討しています」 | 備品もこれから揃える印象 |
| 大切な確認事項 | 「初期案として以下を基本ルールにしています」 | ルールが未確定に見える |
| 代表者について | 「準備しています」「最初の小規模導入に向けて〜伺っている段階」 | まだ1件も動いていない印象 |
| まず伺いたいこと | 「できるかどうか」をゼロから尋ねる構成 | 実例がないので相手に判断材料が少ない |

**最も効く改善ポイント**：「検討しています／初期案として／準備しています」の3系統。ここを「小規模な試験運用を行い、そこで整理した型がある」に置き換えると、事実を誇張せずに安心感が出る。

## 2. 実績1件あり版の基本方針

### どこまで実績を出すべきか（安全圏）
- 「宿泊施設で**小規模な試験運用を行っている／行った**」という事実レベルまで。
- 「貸出に必要な備品・注意事項・同意確認・返却確認の**一式を実際に用意し、フロント運用に合わせて調整した**」という運用整備レベルまで。
- 「**大きなトラブルや過度な負担は確認されていない**」という控えめな言い方まで（保証はしない）。

### どこから先は誇張になるか（NG圏）
- 「導入実績多数」「効果実証済み」「トラブルなしを保証」→ 1件かつ未検証なので誇張。
- 貸出件数・防止効果・宿泊者満足などの**数値化**→【要事実確認】、原則出さない。
- 施設名の明示→【要事実確認】（先方の公開許可が必要）。

### 「実績あり」と「各施設に合わせて調整」のバランス
- 構文を固定する：**「すでに整理した型がある（安心）／ただし施設ごとに合わせて調整する（押し付けない）」** を必ずワンセットで書く。
- 「型はある、でも貴施設仕様に合わせる」と言うことで、実績アピールと相談トーンを両立できる。

### 「初期案ですが」の代わりに使うべき言い方
- ✕「初期案として以下を基本ルールにしています」
- ○「小規模な試験運用をもとに、以下を基本的な運用ルールとして整理しています」
- ○「実際の運用で使った型をもとに〜」

## 10. 実績情報として最低限必要な確認事項（公開前チェック）

- [ ] 導入先施設名を**出してよいか**（先方の明示的な公開許可。無断記載は不可）
- [ ] 施設名を出さない場合、どの抽象度まで許されるか（「ある宿泊施設で」「北海道内の宿泊施設で」など）
- [ ] 「導入」と呼ぶか「試験運用／小規模運用」と呼ぶか（実態に合う語を統一。仮前提では「試験運用」が安全）
- [ ] 試験運用の**期間**を出すか／出さないか
- [ ] 貸出件数・利用実数を出せるか（原則出さない方針でよいか）

- [ ] 「効果」に触れるか（原則触れない。触れる場合は数値・断定を避ける）
- [ ] 現在も運用継続中か（現在形「運用しています」か過去形「運用しました」かの判断材料）

## 11. 推奨する言い換え集

| 避けたい表現 | 言い換え案 | 理由 |

| 初期案ですが | 小規模な試験運用をもとに整理した | 未確定でなく、実運用に裏付けがある印象に |

## 12. 結論

**判断：「実績情報の事実確認後にHTML反映」**（＝今はまだ文案試作に留める）。

理由：
- 本文案の前提（1件の小規模試験運用）は**仮前提**であり、事実として確定・公開許可が取れていない。
- 「運用しています／整えました」を事実確認なしに公開すると、実態と乖離した場合に最も重い信頼毀損になる（実績表現は誇張すると致命的）。
- 第10節のチェック（特に①施設名の公開可否、②「試験運用」か「導入」かの語、③現在形/過去形）が固まれば、第9節の優先度「高」から段階反映が可能。
- 施設名を伏せる前提（「ある宿泊施設で小規模に運用」）であれば、事実が1件確定し次第、施設名なしでの反映は比較的安全に行える。

つまり**「事実が1件確定 → 施設名を伏せた表現で高優先度箇所から反映」**が現実的な進め方。
