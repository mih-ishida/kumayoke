# 施設別ページ 文面ガイド

最終更新: 2026-06-02
文面基準: `web/f/morappu-camp.html`

このファイルは、施設別ページを書くときの軽いガイドです。
正典は長いルール文書ではなく、`web/f/morappu-camp.html` の文面そのものとします。

## 基本方針

- まず、施設向けに個別に用意したページだと伝わることを優先する
- ページの目的は「その施設でクマ撃退スプレー貸出が現実的に成り立つかを確認すること」
- 文体は短く、あたたかく、実務的にする
- 売り込みすぎない
- 法務・安全の話は消しすぎず、正式に進める前に書面整理が必要だと分かる程度に留める

## 必ず残す方向

- 読んでくれたことへのお礼
- その施設に合いそうだと考えた自然な理由
- 施設側の作業はシンプルに 3 点
  - 受け渡し
  - 返却時の確認
  - 簡単な記録
- 返信しやすい締め方
- 代表者の人柄と信頼感

## 文面ルール

- `クマヨケは運用支援` と伝える
- スプレー販売、登山ガイド、安全保証ではないことは簡潔に触れる
- FAQ の `誰にでも貸せますか？` は使わず、`貸出対象はどのように決まりますか？` に寄せる
- `貸出・説明確認アプリ` は、現行提供を断定せず将来方向として扱う
- 具体的な価格は出さない
- 安全を保証する言い方はしない
- 施設に責任がないと読める言い方はしない
- 正式に進める前に、責任分担・保険・事故時対応・使用や破損時の費用負担を文書で整理する考えは残す
