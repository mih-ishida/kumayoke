# 施設別HTML 正典ルール

作成日：2026-06-02
基準HTML：`web/f/morappu-camp.html`

## 1. このファイルの位置づけ

このファイルは、現行の初回連絡対象5件の施設別HTMLを作成・修正する際の正典ルールである。

- 基準HTML：`web/f/morappu-camp.html`
- 現行対象：`bifue-camp` / `morappu-camp` / `jozankei-nature-village` / `forever-camping-paradise` / `izumisawa-nature-forest-camp`

## 2. 基本方針

- 初回営業ページなので、説明しすぎない
- 「導入してください」ではなく「現場に合う余地があるか確認したい」トーンにする
- 施設側作業はゼロとは言わず、3項目程度に絞る
- 価格・料金・保証金・有料導入・安全保証・責任免除に読める表現は出さない
- `貸出・返却管理アプリ` は使わず、必要なら `トラブル時・連絡先フォロー` を使う
- `15分`、`面談前提`、`電話前提` の表現は使わない
- 施設名・運営体制の未確認事項は断定しない

## 3. 共通構成

1. ファーストビュー
2. このページについて
3. クマヨケとは
4. 施設に合いそうだと考えた理由
5. 施設様にお願いする作業
6. クマヨケ側で用意するもの
7. 大切な確認事項について
8. よくある質問
9. まず伺いたいこと
10. 代表者について
11. 連絡先
12. フッター

## 4. セクション別ルール

- H1 は自然な2〜3行に分け、`クマ撃退スプレー` には `<span class="nowrap">` を付ける
- [4] の理由は3項目前後に絞る
- [5] の主な作業は `利用者への受け渡し` `返却時の確認` `簡単な記録`
- [6] の用意するものは、備品・書類・確認の流れに留める
- [7] は基本ルールの説明に留め、費用・保険・責任の細部は書かない
- [9] はメール返信しやすい内容にする
- [11] は `メールでご連絡する` のCTAのみを置く

## 6. 避ける表現

- 価格 / 料金 / 金額 / 円
- 保証金
- 有料導入
- 賠償責任保険
- 責任分担の詳細
- 安全を保証する表現
- 施設に責任がないと受け取れる表現
- 貸出・返却管理アプリ
- 15分ヒアリング / 15分で分かること
- 導入済み / 提携済み / 許諾済みのように読める表現

## 7. 横展開時の置換ルール

- 地域名、対象者表記、受付/フロント表現は施設タイプに合わせて変える
- eyebrow は `〇〇 ご担当者様へ`
- 件名例は `クマヨケについて（〇〇様）`
- meta description は本文トーンに合わせて更新
- 代表者・CTA文言・メールアドレス・画像パスは共通で固定
