# 施設別ページ 文面ガイド

最終更新: 2026-06-02
文面基準: `web/f/morappu-camp.html`

このファイルは、施設別ページを書くときの軽いガイドです。
正典は長いルール文書ではなく、`web/f/morappu-camp.html` の文面そのものとします。

## 基本方針

- まず、施設向けに個別に用意したページだと伝わることを優先する
- ページの目的は「その施設でクマ撃退スプレー貸出が現実的に成り立つかを確認すること」
- 文体は短く、あたたかく、実務的にする
- 売り込みすぎない
- 法務・安全の話は消しすぎず、正式に進める前に書面整理が必要だと分かる程度に留める
- `クマヨケは、施設が利用者向けにクマ撃退スプレーを管理・貸出できるようにするための運用支援です。` を基本の説明軸にする
- 施設によっては `利用者`、`施設利用者` のほうが自然な場合がある
- `クマヨケとは` は長文化せず、スプレー販売ではないことを簡潔に伝える

## 必ず残す方向

- 読んでくれたことへのお礼
- その施設に合いそうだと考えた自然な理由
- 施設側の作業はシンプルに 3 点
  - 受け渡し
  - 返却時の確認
  - 簡単な記録
- 返信しやすい締め方
- 代表者の人柄と信頼感

## 文面ルール

- `クマヨケは運用支援` と伝える
- スプレー販売、登山ガイド、安全保証ではないことは簡潔に触れる
- FAQ は必要な場合に 3 問構成を優先し、`導入費` や `誰にでも貸せますか？` を戻さない
- `貸出管理アプリ` を使う場合は、今後の運用支援として断定しすぎない
- 具体的な価格は出さない
- 安全を保証する言い方はしない
- 施設に責任がないと読める言い方はしない
- 正式に進める前に、責任分担・保険・事故時対応・使用や破損時の費用負担を文書で整理する考えは残す
