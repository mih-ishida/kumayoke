# 施設別ページ ヒーロー画像ルール

最終更新: 2026-06-03

この文書は、施設別 HTML ページの最初のセクション / hero セクションに、既存の画像をどう割り当てるかだけを定める軽いルールです。

## 目的

- ヒーロー画像は、最初のセクションの視覚的な背景としてだけ使う
- 画像は、施設ごとの印象に合うものを選ぶ
- 場所の文脈に合わない地域画像を、複数ページで共用しない

## 画像の置き場所

- 画像は `web/assets/` に置く
- `web/f/*.html` から参照するときは、相対パスで `../assets/<image-file-name>.png` を使う

## 現在の画像グループ

### A. 支笏湖 / 湖畔系施設

- 使用画像: `hero-shikotsuko-lake.png`
- 現在のページ:
  - `bifue-camp.html`
  - `morappu-camp.html`
- 向いている施設:
  - 支笏湖周辺
  - 湖畔系キャンプ場
  - 湖、森、水辺の印象が自然な施設

### B. 定山渓 / 渓谷・山あい系施設

- 使用画像: `hero-jozankei-valley.png`
- 現在のページ:
  - `jozankei-nature-village.html`
- 向いている施設:
  - 定山渓周辺
  - 渓谷、山あい、森の自然体験系施設
  - 湖畔よりも山や渓谷の印象が自然な施設

### C. 森林キャンプ場 / 一般的な森のアウトドア系施設

- 使用画像: `hero-forest-campsite.png`
- 現在のページ:
  - `forever-camping-paradise.html`
  - `izumisawa-nature-forest-camp.html`
- 向いている施設:
  - 森林キャンプ場
  - 林間サイト
  - 自然の森、キャンプ、アウトドア感が中心の施設
  - 支笏湖や定山渓の固有感を出しすぎない方がよい施設

## CSS の扱い

- ヒーロー section には CSS background として画像を置く
- 読みやすさのため、白の半透明オーバーレイを重ねる
- hero のレイアウトや本文は変えない
- foreground の `<img>` にするのは、どうしても必要な場合だけにする

例:

```css
.hero-photo {
  background:
    linear-gradient(rgba(255,255,255,0.7), rgba(255,255,255,0.7)),
    url("../assets/hero-shikotsuko-lake.png") center / cover no-repeat;
}
```

ページごとに画像を変えるときは、URL だけを差し替える。

## 編集ルール

- ヒーロー画像を変えるときは、ページ文面を書き換えない
- 施設固有の文言は変えない
- 明示されていない限り、非アクティブな歴史ページは変更しない
- 変更は局所的かつ最小限にする
- 新しい施設ページを追加する場合は、まず最も近い画像グループを選ぶ
