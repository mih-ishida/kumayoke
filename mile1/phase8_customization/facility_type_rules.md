# 施設タイプ別メモ（背景資料）

最終更新: 2026-06-02

このファイルは背景メモです。
施設別ページの文面基準としては使わず、語彙の当て方に迷ったときの参考にだけ使います。
実際の文面は `web/f/morappu-camp.html` を先に見て、そこから各施設へ軽く寄せてください。

## 使い方

- 施設タイプからページを組み立てない
- 先に Morappu の温度感を合わせる
- その後で、以下の語の置き換えだけ必要に応じて使う

## 置き換えの目安

- ホテル / 旅館: `宿泊者` `フロント`
- キャンプ場: `宿泊者` または `利用者`、`受付・管理棟`
- 自然体験施設: `宿泊者` を基本に、必要なら `自然体験を楽しむ方`
- 一棟貸し寄り: チェックイン方式に触れたいときだけ軽く調整

## 注意

- タイプ別の generic な書き分けに寄りすぎない
- 既存対策を否定しない
- 危険施設のように書かない
- 施設ごとのページは、その施設向けに用意した感じを優先する
