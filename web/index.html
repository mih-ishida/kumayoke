宿泊施設向け クマヨケご説明ページ

本ページは、クマヨケの概要と運用イメージを短時間でご確認いただくための説明ページです。

クマヨケとは

クマヨケは、宿泊施設のフロントで宿泊者へクマ撃退スプレーを貸し出せるようにする、 遭遇回避を前提とした安全補助オペレーション導入支援です。 スプレー本体だけでなく、同意確認や返却確認まで含めた運用を支援します。

宿泊施設様にお願いする作業

  • フロントでの受け渡し
  • 利用前の同意確認
  • 返却時の確認
  • 会計計上と記録（返却チェック表・返却ログ）

専門的な使用説明をスタッフ様にお願いする前提ではありません。 説明は注意事項・同意書・説明ページで標準化する想定です。

クマヨケ側で用意するもの

  • クマ撃退スプレー本体
  • ホルスター
  • 保管箱
  • 注意事項
  • 利用同意書
  • スタッフ向け手順書
  • 返却チェック表
  • 返却ログ
  • 未返却・破損・使用時の対応フロー
  • 使用期限・個体番号の管理方法

想定する貸出フロー（概要）

  1. 事前準備: 備品・書類・運用手順を準備
  2. 貸出時: 同意確認後に貸出
  3. 返却時: 返却確認と記録
  4. 問題発生時: 事前に定めた対応フローで処理

収益の扱い

宿泊者様からのレンタル料金は、宿泊施設様側の収益として扱っていただく前提です。 クマヨケは導入・運用支援側としてご相談を進めます。

よくあるご質問

ホテル側の作業は増えますか？
受け渡し・同意確認・返却確認が中心です。運用書類はクマヨケ側で用意します。
誰にでも貸し出せますか？
初期案では、宿泊者かつ18歳以上、自然活動目的の方を想定しています。
飛行機への持込・預け入れはできますか？
できません。原則としてホテル返却を前提にします。
使用済みスプレーは再貸出しますか？
しません。未噴射・破損なし・使用期限内のもののみ再貸出対象です。
導入費用はどこで確認できますか？
価格は本ページには記載せず、運用条件を伺ったうえで個別にご相談します。
